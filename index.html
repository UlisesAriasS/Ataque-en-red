Vectores de Ataque Principales

1. Malware

Software Malicioso

Definición: Programas diseñados específicamente para dañar, infiltrarse o tomar control de un sistema de forma oculta.

Características: Alto poder de autorreplicación, capacidad para espiar actividades (spyware) o corromper el núcleo del sistema operativo.

Clasificación: Virus, Gusanos (Worms), Troyanos, Spyware, Adware.

🛡️ Prevención

Antivirus EDR (Endpoint Detection and Response), parcheo de software y control de aplicaciones.

2. Ransomware

Secuestro de Datos

Definición: Malware letal que emplea criptografía para cifrar los archivos de la víctima, pidiendo un rescate a cambio.

Características: Uso de algoritmos de cifrado de grado militar. A menudo paraliza operaciones de empresas enteras hasta que se paga en criptomonedas.

Clasificación: Crypto-ransomware (cifra archivos) y Locker-ransomware (bloquea la pantalla).

🛡️ Prevención

Estrategia de Backup 3-2-1 (copias aisladas/offline) y concienciación sobre phishing.

3. Phishing

Ingeniería Social

Definición: Suplantación de identidad donde el atacante finge ser una entidad de confianza (banco, empresa) para robar datos.

Características: Explota la psicología humana (urgencia o miedo) más que fallos técnicos. Usa correos electrónicos o SMS falsificados.

Clasificación: Spear Phishing (dirigido), Whaling (altos ejecutivos), Vishing (llamadas), Smishing (SMS).

🛡️ Prevención

Autenticación Multifactor (MFA), capacitación de usuarios y filtros antispam avanzados.

4. DDoS

Denegación de Servicio

Definición: Sobrecarga intencional de un servidor o red con tráfico ilegítimo masivo hasta colapsarlo.

Características: Emplea un ejército de dispositivos "zombies" (Botnet) distribuidos globalmente, lo que dificulta bloquear el ataque.

Clasificación: Ataques volumétricos, ataques de estado de protocolo (SYN flood) y capa de aplicación.

🛡️ Prevención

Servicios de mitigación DDoS en la nube (ej. Cloudflare), balanceadores de carga y Firewalls perimetrales.

5. Man-in-the-Middle

Intercepción de Tráfico

Definición: Intercepción silenciosa de la comunicación entre dos sistemas (ej. usuario y banco).

Características: El atacante puede leer, modificar o inyectar datos en tiempo real. Frecuente en redes Wi-Fi públicas inseguras.

Clasificación: ARP Spoofing, DNS Spoofing, Secuestro de sesión (Session Hijacking).

🛡️ Prevención

Cifrado de extremo a extremo, uso de VPNs y navegación exclusiva bajo protocolos seguros (HTTPS).

6. Inyección SQL

Ataque a Bases de Datos

Definición: Inserción de código malicioso en los inputs de una aplicación para manipular el motor de base de datos SQL.

Características: Permite realizar bypass de pantallas de login, extraer tablas enteras de usuarios o borrar información confidencial.

Clasificación: In-band SQLi, Inferential (Blind) SQLi, Out-of-band SQLi.

🛡️ Prevención

Uso estricto de Consultas Parametrizadas (Prepared Statements), ORMs y validación de entrada.
